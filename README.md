# 🕌 মাদরাসা ম্যানেজমেন্ট সিস্টেম

বাংলা ভাষায় একটি সম্পূর্ণ মাদরাসা ম্যানেজমেন্ট ওয়েব অ্যাপ্লিকেশন।

## ফিচারসমূহ
- 🔐 অ্যাডমিন লগইন (JWT ভিত্তিক)
- 📊 ড্যাশবোর্ড — সারসংক্ষেপ, আজকের হাজিরা, আদায়
- 👨‍🎓 শিক্ষার্থী ব্যবস্থাপনা — নতুন ভর্তি, শ্রেণি ভিত্তিক তালিকা, সার্চ, প্রোফাইল
- 🏫 শ্রেণি ব্যবস্থাপনা
- 👨‍🏫 শিক্ষক ব্যবস্থাপনা
- 🗓️ শিক্ষার্থী ও শিক্ষক হাজিরা (উপস্থিত/অনুপস্থিত/ছুটি)
- 📈 মাসিক পাঠদানের রিপোর্ট (উপস্থিতির হারসহ)
- 💰 মাসিক বেতন আদায় (নগদ/বিকাশ/নগদ অ্যাপ) ও রশিদ
- ⚠️ বকেয়া বেতন হিসাব (মাস ভিত্তিক বিস্তারিত)
- 🧾 শিক্ষক বেতন প্রদান ও রশিদ
- 📝 পরীক্ষা তৈরি (বিষয় ও পূর্ণমান নির্ধারণ) ও নম্বর এন্ট্রি
- 🏆 একক মার্কশিট ও সমন্বিত রেজাল্ট শিট (মেধাক্রম, গ্রেড, পাস/ফেল)
- 🖨️ সব রিপোর্ট, মার্কশিট, রেজাল্ট ও রশিদ **পিডিএফ** হিসেবে ডাউনলোড (প্রিন্ট → Save as PDF, বাংলা ফন্ট নিখুঁতভাবে রেন্ডার হয়)

## টেকনোলজি
- **ফ্রন্টএন্ড:** React 18 + Vite + Tailwind CSS v4 (Hind Siliguri ফন্ট, মোবাইল রেসপন্সিভ)
- **ব্যাকএন্ড:** Node.js + Express
- **ডেটাবেজ:** SQLite (better-sqlite3) — `data/madrasa.db`
- **অথেন্টিকেশন:** bcryptjs + jsonwebtoken

## ইনস্টলেশন

```bash
# 1. ব্যাকএন্ড ডিপেন্ডেন্সি
cd server && npm install

# 2. ফ্রন্টএন্ড ডিপেন্ডেন্সি
cd ../client && npm install
```

## চালানোর নিয়ম

### ডেভেলপমেন্ট মোড (২টি টার্মিনাল)

```bash
# টার্মিনাল ১ — ব্যাকএন্ড (http://localhost:4000)
cd server && npm start

# টার্মিনাল ২ — ফ্রন্টএন্ড (http://localhost:5173)
cd client && npm run dev
```

### প্রোডাকশন মোড (একটি টার্মিনাল)

```bash
cd client && npm run build
cd ../server && npm start
# ব্রাউজারে: http://localhost:4000
```

প্রথম চালু হলে ডেটাবেজ খালি থাকলে ডেমো ডেটা (শ্রেণি, শিক্ষার্থী, শিক্ষক, পরীক্ষা, নম্বর, বেতন) স্বয়ংক্রিয়ভাবে যোগ হয়।

## ডেমো লগইন
- ইউজারনেম: `admin`
- পাসওয়ার্ড: `admin123`

## প্রোডাকশনের আগে অবশ্যই
- `server/index.js` এ `JWT_SECRET` এনভায়রনমেন্ট ভেরিয়েবল সেট করুন
- ডিফল্ট অ্যাডমিন পাসওয়ার্ড পরিবর্তন করুন
- `client/src/components/ui.jsx` এর `PrintHeader` কম্পোনেন্টে নিজের মাদরাসার নাম, ঠিকানা ও লোগো বসান
