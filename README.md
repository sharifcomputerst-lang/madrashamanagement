# 🕌 মাদরাসা ম্যানেজমেন্ট সিস্টেম (সম্পূর্ণ অফলাইন)

বাংলা ভাষায় একটি **সম্পূর্ণ অফলাইন** মাদরাসা ম্যানেজমেন্ট ওয়েব অ্যাপ্লিকেশন। **কোনো সার্ভার লাগে না** — সব ডেটা আপনার ডিভাইসের ব্রাউজারেই (IndexedDB) সংরক্ষিত থাকে।

## 🎯 অফলাইন মানে কী?

- ❌ কোনো সার্ভার, ডেটাবেস সার্ভার বা ইন্টারনেট লাগে না
- ✅ `npm run build` এর পর `client/dist/index.html` **ডাবল-ক্লিক করলেই** অ্যাপ চালু হবে (`file://` দিয়েও)
- ✅ ইন্টারনেট হলে PWA হিসেবে ব্রাউজারে **ইনস্টল** করা যাবে (যেকোনো static hosting এ ফাইলগুলো রাখলেই হবে)
- ⚠️ ডেটা **প্রতি ডিভাইস / প্রতি ব্রাউজারে আলাদা** থাকে। ব্রাউজারের ক্লিয়ার ডেটা করলে ডেটা মুছে যায় — নিয়মিত রিপোর্ট/রশিদ PDF-এ সংরক্ষণ করুন।

## ✨ ফিচারসমূহ
- 🔐 অ্যাডমিন লগইন (ডেমো: **admin / admin123**)
- 📊 ড্যাশবোর্ড — সারসংক্ষেপ, আজকের হাজিরা, আদায়
- 👨‍🎓 নতুন ভর্তি ও শিক্ষার্থী ব্যবস্থাপনা — শ্রেণি ভিত্তিক তালিকা, সার্চ, প্রোফাইল
- 🏫 শ্রেণি ব্যবস্থাপনা
- 👨‍🏫 শিক্ষক ব্যবস্থাপনা
- 🗓️ শিক্ষার্থী ও শিক্ষক হাজিরা (উপস্থিত/অনুপস্থিত/ছুটি)
- 📈 মাসিক পাঠদানের রিপোর্ট (উপস্থিতির হারসহ)
- 💰 মাসিক বেতন আদায় (নগদ/বিকাশ) ও রশিদ
- ⚠️ বকেয়া বেতন হিসাব (মাস ভিত্তিক বিস্তারিত)
- 🧾 শিক্ষক বেতন প্রদান ও রশিদ
- 📝 পরীক্ষা তৈরি (বিষয় ও পূর্ণমান নির্ধারণ) ও নম্বর এন্ট্রি
- 🏆 একক মার্কশিট ও সমন্বিত রেজাল্ট শিট (মেধাক্রম, গ্রেড, পাস/ফেল)
- 🖨️ সব রিপোর্ট, মার্কশিট, রেজাল্ট ও রশিদ **PDF** হিসেবে ডাউনলোড (প্রিন্ট → Save as PDF, বাংলা ফন্ট নিখুঁতভাবে রেন্ডার হয়)

## 🚀 ব্যবহার শুরু

### সহজ উপায় (বিল্ড করা ফাইল)
```bash
npm install
npm run build
```
তারপর `client/dist/index.html` ফাইলটি **ডাবল-ক্লিক** করুন — ব্রাউজারে অ্যাপ খুলে যাবে। প্রথমবার খুললেই ডেমো ডেটা (৫টি শ্রেণি, ১০ জন শিক্ষার্থী, ৩ জন শিক্ষক, পরীক্ষা ও বেতনের ইতিহাস) স্বয়ংক্রিয়ভাবে তৈরি হবে।

**ডেমো লগইন:** ইউজারনেম `admin`, পাসওয়ার্ড `admin123`

> 💡 আরও ভালো অভিজ্ঞতার জন্য: ইন্টারনেট আছে এমন অবস্থায় অ্যাপটি একবার যেকোনো static hosting বা `localhost` থেকে খুললে Service Worker ভেতরে ক্যাশ করে ফেলবে এবং পরে ইন্টারনেট ছাড়াও ইনস্টল করা অ্যাপ হিসেবে চলবে।

### ডেভেলপমেন্ট মোড
```bash
npm run dev      # http://localhost:5173
```

## 🖨️ PDF এক্সপোর্ট
যেকোনো রিপোর্টে **"পিডিএফ"** বোতামে ক্লিক → ব্রাউজারের প্রিন্ট ডায়ালগ খুলবে → *Save as PDF* নির্বাচন করুন। বাংলা যুক্তাক্ষর নিখুঁতভাবে সংরক্ষিত হয়।

## 🏗️ টেকনোলজি
- **Frontend:** React 18 + Vite + Tailwind CSS v4
- **ডেটা সংরক্ষণ:** IndexedDB (Dexie.js) — ব্রাউজারের ভেতরেই
- **লগইন:** bcrypt পাসওয়ার্ড হ্যাশ, লোকাল সেশন টোকেন
- **PWA:** manifest + Service Worker (stale-while-revalidate)
- **HashRouter:** `file://` থেকেও SPA রাউটিং কাজ করে

## ⚠️ গুরুত্বপূর্ণ নোট
- ডেটা ডিভাইসে থাকে — **অন্য কোনো ডিভাইসে সচল হবে না** এবং ইনকগনিটো মোডে বন্ধ করলেই মুছে যায়।
- একই ব্রাউজারে প্রোডাকশন ডেটা ও ডেমো ডেটা মেশাতে না চাইলে আলাদা ব্রাউজার প্রোফাইল ব্যবহার করুন।
